# TOXIC MODE voicelines

Name each file `<key>_<n>.wav` (n = 1, 2, 3…), drop it here, and bump that
key's count in `js/roast.js`'s `ROASTS`. A key with no lines falls back to
`generic`. One random line plays per death (never the same twice in a row).
